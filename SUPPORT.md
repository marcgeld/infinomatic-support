# Support

Thank you for using Infinomatic! Here's how to get help:

## How to Get Support

1. **Search existing issues** — Browse [open and closed issues](../../issues?q=) to see if your question or problem has already been addressed.

2. **Open a new issue** — If you can't find an answer, [open an issue](../../issues/new/choose) using the appropriate template:
   - **Bug Report** — for unexpected behavior or errors.
   - **Feature Request** — for new features or improvements.
   - **Question** — for general questions about using Infinomatic.

## Response Times

We aim to respond to all new issues within a reasonable timeframe. Response times may vary depending on issue complexity and team availability.

## Security Issues

If you discover a security vulnerability, **please do not open a public issue**. Instead, contact the maintainers directly through the repository's security advisory feature or via a private channel.
