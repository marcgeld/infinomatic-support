## Getting Help

If you need help using Infinomatic, please:

1. **Search existing issues** – Your question may have already been answered. Use the [Issues](../../issues) search to look for similar topics.
2. **Read the documentation** – Check the project's official documentation for guides and FAQs.
3. **Open a new issue** – If you still need help, [open a new issue](../../issues/new/choose) using the appropriate template.

---

## Reporting a Bug

Found something that isn't working as expected? Please [open a bug report](../../issues/new?template=bug_report.md) and include:

- A clear and descriptive title.
- Steps to reproduce the issue.
- Expected vs. actual behavior.
- Screenshots or logs (if applicable).
- Your environment (OS, browser/app version, etc.).

---

## Requesting a Feature

Have an idea for an improvement or a new feature? [Open a feature request](../../issues/new?template=feature_request.md) and tell us:

- What problem the feature would solve.
- A description of the proposed solution.
- Any alternatives you've considered.

---

## Before You Open an Issue

To help us respond quickly, please:

- ✅ Search existing open **and** closed issues before creating a new one.
- ✅ Use one of the provided issue templates.
- ✅ Provide as much detail as possible.
- ✅ Stay on topic — one issue per report.

---

## Issue Labels

| Label | Description |
|---|---|
| `bug` | Something isn't working |
| `enhancement` | New feature or improvement request |
| `question` | Further information is requested |
| `documentation` | Improvements or additions to documentation |
| `duplicate` | This issue or request already exists |
| `wontfix` | This will not be worked on |
| `help wanted` | Extra attention is needed |

This project follows a standard code of conduct. Please be respectful and constructive in all interactions. Issues that violate this policy may be closed or hidden without notice.
